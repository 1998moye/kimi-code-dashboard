# 变更记录 - 2026-08-24 09:42:29

## 为什么要改

Kimi 网页会员额度接口仍使用 `GetSubscriptionStats`，但近期响应字段同时存在 snake_case 版本。插件只解析旧的 camelCase 字段，导致使用新的有效网页 Token 时无法展示月度总量和赠送额度。

## 做了什么

- 兼容 `subscription_balance`、`gift_balances`、`amount_used_ratio`、`expire_time` 等 snake_case 字段，同时保留旧 camelCase 解析。
- 展示网页接口新增的 `kimi_code_used_ratio`，说明会员月度总量中 Kimi Code 的消耗比例。
- 保留原有 Token 过期、账号不一致及请求失败时的降级提示。
- 保存网页 Token 前校验 JWT 过期时间；保存后仅在实际拉取成功时提示已验证，避免“已保存”被误认为额度已加载。
- 获取说明改为优先从 Network 请求的 `Authorization` 头复制当前 access token；Cookie 仅作备用，避免网页会话仍有效但 Cookie 里的旧 access token 已过期。
- 自动提取脚本改为扫描 Cookie、localStorage、sessionStorage 内嵌的全部 JWT，并自动过滤过期 Token；将手动查看 Network 调整为自动提取失败时的备用方案。
- 自动提取脚本与保存逻辑均排除 `typ: refresh` 的刷新令牌，仅接受可用于会员接口的 access token，避免错误保存后返回 401。

## 改动位置

- `lib/quotaClient.js`
- `extension.js`

# 变更记录 - 2026-08-24 10:31:23

### 为什么要改？
网页 token 的有效期可能很短，过期提示出现时，原本默认展开的三种获取说明会长期占用额度面板空间；用户应在需要重新获取 token 时再查看具体操作。

- 保留原有 token 输入、保存、打开额度页和复制提取脚本按钮，以及全部获取步骤和过期 token 过滤说明。
- 将扩展版本从 `0.3.7` 递增至 `0.3.8`，用于发布本次界面优化的独立 VSIX 安装包。

### 改动位置

- `extension.js`
- `package.json`
